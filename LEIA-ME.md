## Especificações técnicas dos arquivos
- **Vetores:** todos em **SVG** (padrão aberto, escalável, pronto para Font Awesome/insert). Convertíveis para AI/EPS/PDF em qualquer editor.
- **Textos dos logotipos:** fonte de composição `Archivo`, `Space Grotesk`, `IBM Plex Mono` ou `Fraunces` (conforme proposta). Se a fonte não estiver instalada no visualizador, o SVG cai na fallback system — converta para curvas antes de enviar a gráfica se necessário.
- **Cores:** cada prancha traz HEX + RGB + CMYK + referência Pantone aproximada. Confirme prova de tinta.

## Avisos legais (importante)
1. **Registro INPI:** recomendamos busca prévia de anterioridade antes do registro. A vencedora (04) foi desenhada com forma própria (portal + X em subtração) para maximizar chances, mas busca formal é obrigatória.
2. Todas as cores Pantone são **aproximações** e devem ser conferidas no guia oficial da cor.
3. Nenhum arquivo desta pasta valida ou oficializa a razão social/CNPJ da empresa — dados corporativos devem ser fornecidos e revisados pelo cliente.
